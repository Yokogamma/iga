# Богатырь (Iga)

Простая браузерная игра для телефона: богатырь на коне разведывает землю в тумане, ставит флаги в посёлках и руководит помощниками — лесорубами, носильщиками и строителями.

**Играть:** https://yokogamma.github.io/Iga/

## Как играть
- Коснись земли — богатырь поедет туда. По дорогам быстрее, реку можно перейти только по мосту.
- Заедь в посёлок — он начнёт служить и давать людей одного вида.
- Каждый посёлок даёт людей одного вида: лесорубов, носильщиков или строителей. Чтобы что-то построить, нужны все три.
- Приказы внизу: рубить лес, построить лагерь 2×2 (большой склад и дом для людей), мост, улучшить посёлок (второй вид людей за 10 дров).
- Носильщики сначала носят дрова на стройки, потом сносят брошенные кучи в амбары посёлков (по 6 брёвен) и на склад лагеря.
- Брошенные дрова гниют и могут загореться, огонь перекидывается на лес.
- «Карта» — общий вид открытых земель; тап по ней отправляет богатыря.

Прогресс сохраняется в браузере устройства.

## Устройство
Один файл `index.html` без сборки и зависимостей (canvas + JavaScript).
